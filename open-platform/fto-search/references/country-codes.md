# 受理局代码参考

## 知识产权五局

| 代码 | 受理局 |
|------|--------|
| `CN` | 中国 |
| `US` | 美国 |
| `EP` | 欧洲专利局 |
| `JP` | 日本 |
| `KR` | 韩国 |

**示例**：
- 仅中国：`["CN"]`
- 中美：`["CN", "US"]`
- 五局：`["CN", "US", "EP", "JP", "KR"]`
