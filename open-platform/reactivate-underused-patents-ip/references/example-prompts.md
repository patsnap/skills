# Example Requests

These examples preserve the source use cases while using internationally appropriate
evidence, authority, valuation, and legal boundaries. Replace bracketed text with the
actual scope.

## Organization-level portfolio activation

```text
Use $reactivate-underused-patents-ip to review the patent portfolio of [organization].
Define and identify underused candidates from available internal and public evidence,
prioritize a decision-appropriate review set, and create an accessible HTML report.
Include portfolio segments, evidence-backed activation options, diligence gates, and
management decisions. Do not infer non-use or transaction readiness from public data alone.
```

## Patent-list health check

```text
Use $reactivate-underused-patents-ip to review my uploaded patent list. Compare retain,
internal reuse, license, assign, collaborate, and abandonment-review scenarios under a
transparent rubric. Create an HTML report with dated status/term evidence, ownership and
encumbrance unknowns, technical/commercial signals, and the professional approvals needed.
```

## Maintenance-fee decision support

```text
Use $reactivate-underused-patents-ip to prepare a maintenance-review brief for patents
with upcoming fee decisions. Show jurisdiction, status and term evidence, portfolio role,
internal use, technical/commercial options, expected costs if supplied, uncertainty, and
owner/counsel/finance decision gates. Do not make a final pay-or-abandon decision.
```

## Outbound licensing opportunity screen

```text
Use $reactivate-underused-patents-ip to identify portfolio assets that may warrant an
outbound-licensing screen. Create an internal HTML opportunity list grouped by field of
use and candidate counterparty type. Distinguish observed evidence, inferred fit, rights
diligence, and authorized next steps; do not represent any organization as interested.
```

## Patent transfer package design

```text
Use $reactivate-underused-patents-ip to assess patents in [technical domains] and design
evidence-supported candidate assignment or licensing packages. Explain the shared
technical proposition, rights/ownership/encumbrance checks, candidate-counterparty
profiles, transaction-structure options, valuation inputs if verified, and unresolved
risks. Do not fabricate a valuation range or buyer demand.
```

## Internal R&D reuse

```text
Use $reactivate-underused-patents-ip to determine whether underused portfolio evidence
could support [new product or R&D program]. Produce an HTML reuse brief mapping patents,
know-how and supporting materials to product scenarios, evidence maturity, implementation
dependencies, technical validation work, affected teams, and IP/legal review gates.
```

## Candidate counterparty research

```text
Use $reactivate-underused-patents-ip to research possible licensees, assignees, or
collaborators for these patents. Resolve each legal entity; show technical and rights fit,
current dated business/R&D signals, exclusions, uncertainty, diligence, and an internal
outreach hypothesis. Do not send messages or claim interest, need, budget, or infringement.
```

## Transaction-readiness review

```text
Use $reactivate-underused-patents-ip to prepare a pre-transaction readiness review for
this proposed patent package. Check available ownership, chain of title, co-owners,
licenses, security interests, status, term, family, challenges, funding obligations,
confidential materials, and jurisdiction-specific restrictions. Generate an HTML report
that separates database signals from items requiring official-register or counsel review.
```

## Management one-page brief

```text
Use $reactivate-underused-patents-ip to create a one-page management HTML brief. Show the
defined review population, evidence-based portfolio segments, activation scenarios,
decision gates, top supported actions, unresolved exposure, and a 30/60/90-day plan.
Do not invent portfolio value, progress, owners, counterparties, or dates.
```

## External-ready deliverable

```text
Use $reactivate-underused-patents-ip to create an external-ready HTML report and, if I
explicitly request it and the environment can verify rendering, a PDF. Use an international
Swiss/scientific executive style. Include an NDA-safe summary, portfolio evidence,
candidate transaction routes, diligence status, and action plan; remove confidential
technical detail, personal data, internal thresholds, and unsupported valuation language.
```

## Prompt adaptation checklist

- Define the owner, portfolio, jurisdictions, date cutoff, and transaction objective.
- Identify whether internal-use, transaction-history, fee, cost, and authority records
  are available.
- State the confidentiality and intended audience.
- Choose requested formats rather than assuming every format.
- Require current sources and evidence states.
- Keep valuation, maintenance, abandonment, licensing, assignment, pledge, and outreach
  decisions subject to the appropriate business, legal, finance, tax, regulatory, and
  technical reviews.
