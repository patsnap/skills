# European Patent Translation Reference

## Scope

Use for an EP application or EPO-phase filing-support draft based on Chinese source material.
Use English unless the user requests French or German and qualified language review is available.
Verify current EPO filing, translation, sequence-listing, form, and deadline requirements for the actual route.

## Source-faithfulness controls

- Preserve direct and unambiguous support for every translated feature.
- Do not add technical effects, parameters, examples, definitions, or fallback positions.
- Preserve layered embodiments and alternatives already present in the source.
- Flag any wording that may alter added-matter, support, clarity, or claim-scope analysis.
- Keep a bilingual terminology and ambiguity register with source locators.

## Drafting focus

- Use EPO-oriented patent English, not literal Chinese syntax.
- Keep technical character and concrete technical features visible where the source supports them.
- Avoid result-only language when supported structures or steps are disclosed.
- Translate functional features only to the extent supported by the source and implementation disclosure.
- Preserve claim categories and claim dependencies exactly unless counsel approves a documented change.

## Recommended section order

```text
Title
Description
  Technical Field
  Background Art
  Summary of Invention
  Brief Description of Drawings
  Detailed Description of Embodiments
Claims
Abstract
Drawings / Reference Signs
Sequence Listing, if applicable
```

## Claim-language controls

- Use “comprising” for an open Chinese inclusion term unless the source clearly requires closed scope.
- Establish antecedent basis consistently for components, relationships, and data objects.
- Avoid unnecessary “means for” phrasing and flag functional-language implications.
- Keep apparatus, system, method, process, use, and computer-readable-medium categories distinct.
- Preserve only technically or expressly required method-step order.
- Keep optional, preferred, exemplary, and alternative subject matter non-mandatory.
- Preserve numerical endpoints, units, test conditions, and significant qualifiers.
- Do not convert purpose language into an unsupported structural limitation or vice versa.

## Translation QA

- Map each independent claim limitation back to the Chinese source.
- Verify dependency, multiple dependency, claim numbering, and category.
- Check that every claim term has consistent description support.
- Reconcile drawing signs and figure labels against the translated terminology.
- Confirm that problem/effect statements are no stronger than the source.
- Flag possible clarity, support, enablement, unity, and added-matter concerns for counsel.
- Record unresolved ambiguity rather than guessing.

## Professional review gate

The draft must be reviewed for the specific EP route and facts by appropriately qualified European patent counsel.
Do not label the translation filing-ready until that review and any required translator review are complete.
